<p data-importer="text" align="left">## 🎓 Master's Thesis</p>

<p data-importer="text" align="left">### AI-Based Auto-Healing Kubernetes Cluster Using Anomaly Detection and Automation Workflows</p>

<p data-importer="text" align="left">For my Master's thesis, I designed and implemented a modular <strong>Kubernetes auto-healing prototype</strong> that combines monitoring, anomaly detection and automated remediation.</p>

<p data-importer="text" align="left">The project integrates:</p>

<p data-importer="text" align="left">- ☸️ Kubernetes</p>

<p data-importer="text" align="left">- 🐳 Docker</p>

<p data-importer="text" align="left">- 📊 Prometheus</p>

<p data-importer="text" align="left">- 📈 Grafana</p>

<p data-importer="text" align="left">- 🔄 Argo CD</p>

<p data-importer="text" align="left">- ⚙️ Argo Workflows</p>

<p data-importer="text" align="left">- 🚀 KEDA</p>

<p data-importer="text" align="left">- 🐍 Python</p>

<p data-importer="text" align="left">- 🤖 Machine-learning-assisted anomaly detection</p>

<p data-importer="text" align="left">- 🔧 Automated remediation</p>

<p data-importer="text" align="left">The system was evaluated across <strong>seven controlled failure and degradation scenarios</strong>, including:</p>

<p data-importer="text" align="left">1. Sudden traffic spikes</p>

<p data-importer="text" align="left">2. Slow memory leaks</p>

<p data-importer="text" align="left">3. Node degradation</p>

<p data-importer="text" align="left">4. Application slowdown</p>

<p data-importer="text" align="left">5. Suspicious pod behaviour</p>

<p data-importer="text" align="left">6. Faulty deployments</p>

<p data-importer="text" align="left">7. Silent logging failures</p>

<p data-importer="text" align="left">The project explored a feedback loop of:</p>

<p data-importer="text" align="left"><strong>Monitoring → Detection → Decision → Remediation → Recovery</strong></p>

<p data-importer="text" align="left">The work gave me practical experience with Kubernetes operations, GitOps, observability, automation workflows, anomaly detection and reliability engineering.</p>
